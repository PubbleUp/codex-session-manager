# codex-session-manager 0.2.0 更新说明

由银河飞车编写

## 版本信息

- 版本号：`0.2.0`
- 发布日期：2026-08-27
- 适用平台：macOS、Linux、Windows
- 架构支持：`amd64`、`arm64`

## 主要更新

- 新增 Claude Code session 管理，支持按项目扫描和查看本地会话。
- TUI 新增 Codex 与 Claude Code 双来源，按 `Tab` 快速切换。
- 新增 Claude Code session 删除功能，可清理 transcript、tasks、todos、session 环境和文件历史等关联数据。
- 新增 `claude-projects`、`claude-list`、`claude-delete` 命令。
- 新增 `claude_home` 配置，默认读取 `$CLAUDE_CONFIG_DIR` 或 `~/.claude`。
- 优化详情页返回逻辑：按 `Esc` 先返回 session 列表，再返回项目列表。
- 精简 README，突出命令、快捷键、配置与安全说明。

## 使用说明

```bash
cdsm claude-projects
cdsm claude-list [project]
cdsm claude-delete <session-id>
```

启动 TUI 后按 `Tab` 切换 Codex 与 Claude Code。

## 安全说明

- Codex session 的原有备份、移出和恢复逻辑保持不变。
- Claude Code session 删除是永久操作，不会创建备份。
- 当前 `CLAUDE_SESSION_ID` 对应的活动 session 不允许删除。
- 删除时会原子重写 `history.jsonl`，移除目标 session 的历史记录。
- 共享的 `paste-cache` 和全局 plans 不会自动删除。
- 工具不读取或修改 Codex、Claude Code 的认证配置。
